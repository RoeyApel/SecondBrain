# SecondBrain

This is my personal knowledge base.

## Purpose

SecondBrain is used to store:

- Programming knowledge and best practices.
- Development workflows.
- Personal coding preferences.
- Project-related knowledge.
- Claude Code session summaries.

## Important distinction

Programming notes should primarily contain:

- Best practices.
- Recommended patterns.
- Architecture decisions.
- Things I want Claude to follow when writing code.
- Mistakes and anti-patterns to avoid.

Do not turn the vault into a collection of programming tutorials or documentation that can easily be found online.

## Claude Code

When working on programming projects, use relevant information from this vault when it is useful.

Respect the user's documented coding preferences and best practices.

Do not modify or delete existing notes unless explicitly asked.

Before creating a new note, check whether a relevant note already exists.

Prefer updating an existing note over creating duplicate notes.

## Session summaries

When explicitly asked to summarize a session, save the summary in the appropriate location inside SecondBrain.

A session summary should focus on:

- What was done.
- Important decisions.
- Problems encountered.
- Solutions.
- Important lessons.
- Best practices discovered.
- Remaining work.

Do not blindly copy the conversation.

## Notes

Prefer normal Obsidian Markdown.

Use Obsidian wikilinks when linking to other notes:

[[Note Name]]

Keep notes concise and useful.
