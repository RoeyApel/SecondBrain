# Update Coding Standards

Review proposed coding standards from the current session or the user's request.

## Process

1. Read the relevant existing Coding Standards file.
2. Identify whether the proposed rule is genuinely new.
3. Check whether an existing rule already covers it.
4. Check whether the proposal conflicts with another standard.
5. Explain the proposed change briefly.
6. Ask the user for explicit approval before modifying anything.

Never modify Coding Standards without explicit approval.

## When approved

After explicit approval:

- Update only the relevant Coding Standards file.
- Preserve the existing structure.
- Avoid duplicating rules.
- Keep the wording concise and imperative.
- Do not add tutorial material.
- Do not remove an existing rule unless the user explicitly approves its removal.

## After updating

Report:

- Which file changed.
- What was added/changed.
- Why.
