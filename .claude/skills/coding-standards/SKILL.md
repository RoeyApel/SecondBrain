\## Rules



\- Treat these files as the user's preferred coding standards.

\- Apply relevant standards when writing or modifying code.

\- Do not blindly apply standards that are irrelevant to the current project.

\- If a project explicitly requires a different approach, follow the project's requirements.

\- When standards conflict with project-specific instructions, project-specific instructions take precedence.

\- Do not modify the standards files unless explicitly asked.

\- Do not explain every standard to the user. Apply them naturally.
